# Delivery roadmap
Phase 0: foundation deployed, login and organization setup verified. Owner confirmed custom SMTP signup email arrived; account confirmation is recorded. Password-recovery delivery remains a follow-up check.

Phase 1: event setup, registration types, immutable forms, branding/logo, preview/publish, public free registration, receipt and organizer review implemented. Local tests and database concurrency/isolation verified; preview verification and review are tracked in PHASE-1-REPORT.md.

Stop after Phase 1 review. Phase 2 requires explicit authorization and should first design opaque QR credential issuance/revocation and badge assignment, then deliver one badge → scan → checkpoint check-in flow with replay and tenant tests.

Phase 3: provider-based Chapa payments, verification/webhook idempotency/refunds and transactional communications. Later: analytics, custom domains, templates, wallets, matchmaking, kiosks and offline operations. None are current functionality.
