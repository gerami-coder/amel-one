# Delivery roadmap

Phase 0 (in progress): repository, strict application foundation, design tokens and shells, Supabase SSR, organizations, permission model, audit/error architecture, migrations, tests, CI and verified Vercel preview.

Phase 1 (gated on Phase 0): signup, organization onboarding, event setup, registration types, versioned basic forms, branding, preview/publish, public free registration, confirmation and organizer registration list/details. Verify the complete journey before review.

Phase 2 (requires explicit review): badge templates/designer, assignment, opaque QR credentials, digital badge and checkpoint check-in.

Phase 3: provider-based Chapa payments, verification, webhook idempotency, refunds and communication improvements.

Later: analytics, custom domains, duplication/templates, API, wallets, matchmaking, kiosks and offline operations. These are not current implementation commitments.
