# Design system

Amel One uses warm ivory backgrounds, deep teal actions, charcoal text and restrained lime accents. Semantic tokens define surfaces, text, borders, accent, success, warning, danger and focus. Brand configuration owns name and assets.

Use a system sans stack for UI and a restrained serif display accent. Display headings have tight tracking; body text stays readable. Spacing follows 4/8/12/16/24/32/48/64/80/96px. Controls have at least 44px touch targets. Main content is capped at 1280px; forms at 480px. Radius is 10px for controls, 20px for major surfaces. Use borders sparingly.

Desktop dashboard uses a persistent side rail; tablet and mobile use a labelled disclosure menu. Test 320, 375, 768, 1024 and 1440 widths. Tables scroll inside their own region. Focus is visible, errors are linked to fields, status updates are announced, and reduced-motion disables transitions. Use native controls or shadcn primitives with complete accessible composition.
